One read-only overview of everything you have to do.

All My Tasks shows the tasks and events from your task and calendar services side by side, so you can see the work ahead in one place. It only looks: you keep working in the tools you already use. Built with .NET and Avalonia for Windows, macOS and Linux.

One view over everything you already use, read-only

You keep your calendars and task lists where they are. All My Tasks reads them, stores a local copy and lays them out side by side.

Day, week, month and upcoming

Day, week and month grids and an Upcoming list, plus an All tasks view with filtering, sorting and grouping. An Inbox lists open tasks without a date. Click any entry or task to open its details and subtasks.

Many sources, one model

iCalendar feeds, CalDAV, Todoist, personal Microsoft accounts and Google accounts work today, the last two tried on real accounts. Jira Cloud works too, not yet tried on a live site. GitHub and GitLab are planned. Events and tasks stay separate types, so task-only services fit naturally.

Works offline

Everything is synced into a local SQLite store. Restart the app without a connection and your data is still there. A sync engine handles scheduling, backoff and per-source status.

Credentials stay in your keystore

Tokens and passwords go to Windows Credential Manager, the macOS Keychain or the Linux Secret Service. Without a keyring on Linux, an opt-in PIN-protected encrypted file is used, never plaintext.

Quiet in the system tray

Closing the window hides it to the tray so syncing carries on. Start with only the tray icon using --tray, or turn the behaviour off in Settings.

Light, dark and cross-platform

One Avalonia codebase runs on Windows, macOS and Linux and follows the operating system's light or dark theme.

Providers

Version 1 is a read-only overview. GitHub and GitLab are planned for version 1; writing back is a version 2 goal.

iCalendar feeds Paste a public .ics URL. Conditional fetching and full recurrence expansion. Available
CalDAV Calendar events with incremental sync. Checked by hand against Radicale; Nextcloud and hosted services still need verifying. Available
Todoist Tasks, using a personal API token. Completing tasks is an early, opt-in preview of version 2 write support. Available
Google Calendar and Tasks Read-only, one sign-in for both through OAuth in your browser. For now you create your own OAuth client and paste its ID and secret; tried on a real account. Experimental
Jira Open issues assigned to you on Jira Cloud, with their due dates, using your email and an API token. Not yet tried on a live site. Experimental
GitHub Issues and pull requests assigned to you or waiting for your review. Planned
GitLab Issues and merge requests assigned to you or waiting for your review, on gitlab.com or your own server. Planned
Outlook calendar and Microsoft To Do Outlook calendar and To Do for personal Microsoft accounts through Microsoft Graph, one shared sign-in. You register a free app and paste its client ID; tried on a real account. Work accounts later. Experimental

How it's built

Logic lives in a UI-free core with heavy tests. The Avalonia layer only draws what the core has already worked out.

AllMyTasksThe Avalonia desktop app: views and view models.
AllMyTasks.CoreTasks, events, providers, sync, and the day, week, month and upcoming layout maths.
AllMyTasks.Providers.ICaliCalendar feed and CalDAV providers.
AllMyTasks.Providers.TodoistTodoist task provider.
AllMyTasks.Providers.MicrosoftOutlook calendar and Microsoft To Do.
AllMyTasks.Storage.SqliteLocal store, migrations, settings.
AllMyTasks.SecretsPer-OS secret backends.
tests/xUnit tests for Core and each provider.

Everything comes from a provider

There are no local-only items. The app is a lens over the services you already use.

Time zones and recurrence get real tests

All-day and timed values are distinct types, one shared expander built on Ical.Net, and fixtures cover DST days, overlaps and multi-day events.

Calm by default

Each source gets one colour. Red is reserved for what needs attention: overdue items and sync problems.

Roadmap

The goal is a single, read-only place to see tasks and events from many sources, for a better overview of the work to be done.

Version 1: read-only overview

  • General framework: model, providers, local storage, sync (built)
  • Todoist, Microsoft Outlook and To Do, Google Calendar and Tasks (built)
  • GitHub and GitLab (planned)
  • Views: calendar grids (day, week, month), Upcoming and All tasks (built)
  • Inbox: tasks without a date (built)
  • Verified Google client, live-account checks, installers

Version 2

  • More services (to be chosen)
  • Write support: complete tasks, change task dates, reschedule events
  • Todoist task completion already exists as an opt-in preview

Further research

  • Runtime plug-in support
  • MCP support
  • AI summaries and planning with local models

Get started

Prefer a packaged build? See Download. To build it from source, You need the .NET 10 SDK.

git clone https://github.com/jkruza/allmytasks
cd allmytasks
dotnet build AllMyTasks.slnx
dotnet test --solution AllMyTasks.slnx
dotnet run --project src/AllMyTasks

On Linux the tray icon needs a StatusNotifier or AppIndicator host. KDE, Xfce, Cinnamon and MATE include one; GNOME needs the AppIndicator extension.
