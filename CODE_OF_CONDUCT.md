# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. By taking part in this project you agree to follow it.

## In short

- Be respectful and welcoming, whatever someone's background or experience.
- Give and accept constructive feedback gracefully.
- No harassment, insults, personal attacks, or publishing others' private information.

## Reporting

If someone's behavior bothers you, contact the maintainer, [@jkruza](https://github.com/jkruza),
privately. For example, use GitHub's private vulnerability reporting form from
[SECURITY.md](SECURITY.md) and say it's a conduct report. Reports are handled
confidentially. The maintainer may remove comments, commits or contributions, or
ban contributors, as described in the Contributor Covenant's enforcement guidelines.
