# App and tray icon

Tracked in [#47](https://github.com/jkruza/allmytasks/issues/47).

The "three lines" logo from the [project site](project-site.md) header, used as the window icon,
the Windows executable icon and the system tray icon, replacing the placeholder tray icon.

## The logo

Three left-aligned rounded bars, 5 units tall, 3 apart, corner radius 2, widths 22, 16 and 10, in
blue `#3b82f6`, green `#10b981` and amber `#f59e0b`. These are the values in the site header
(`site/index.html`); if the logo changes there, change `scripts/make-icons.py` too and regenerate.

## Files

All in `src/AllMyTasks/Assets/`, generated by `python3 scripts/make-icons.py` (needs Pillow) and committed,
so building the app needs no Python.

| File | Used for | Look |
| --- | --- | --- |
| `app.png` (256 px) | Window icon (title bar, taskbar, Alt+Tab; Linux window managers) | Bars on a dark slate rounded tile, readable on light and dark |
| `app.ico` (16 to 256 px) | Windows executable icon (`ApplicationIcon`) | Same as `app.png` |
| `tray.png` (64 px) | Tray icon | Bars only on a transparent background, filling the canvas, so they stay legible at 16 to 24 px |

## Wiring

- `MainWindow.axaml` sets `Icon="/Assets/app.png"`.
- `AllMyTasks.csproj` sets `ApplicationIcon` to `Assets\app.ico`. This is what Explorer and the taskbar
  show for the published `AllMyTasks.exe`.
- `TrayService` already loads `Assets/tray.png` from the assembly resources.

## Non-goals

- A macOS `.icns` or `.app` bundle. Releases are zip and tar.gz archives of the binary, not bundles, so
  the macOS Dock keeps the default icon for now. Revisit when macOS packaging is designed.
- A Linux `.desktop` entry or hicolor icon set; there is no installer yet.
- A monochrome or template tray icon for the macOS menu bar and dark Linux panels. The coloured bars are used everywhere.
- Icons for the secondary dialogs.

## Checks

The icon is a visual change with no logic. Verify by building and running: window and tray show the logo.
